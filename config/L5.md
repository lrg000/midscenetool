# L3 / L4 / L5 框架（无 Appium）

```
              AI Test Agent（Midscene + checkpoint + diagnose）
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
      App        Backend      Data
        │           │           │
    Midscene      HTTP       MySQL
   (视觉执行)   config/l5    config/l5
                    │           │
                    └─────┬─────┘
                          ↓
                    快照 store（session.l5）
                          ↓
                    rules（规则引擎）
                          ↓
                    diagnose（失败/不一致推理）
                          ↓
                 midscene_run/l5/*-diagnose.md
```

你日常只改：

1. `.env`：`MYSQL_*`、`API_BASE_URL`（token / userCode / marketId 登录后由 H5 JS 注入）
2. [`config/l5.yaml`](l5.yaml)：`apis` / `sqls` / `rules` / `explore`
3. 在页面 YAML 里粘贴 [`l5-checkpoint-step.example.yaml`](l5-checkpoint-step.example.yaml)

L3：`explore.enabled: true` 后 `npm run test:l3:explore`  
L4：`type: checkpoint` + `observe.optional: true`（库未配时不拖死 UI 用例）  
L5：步骤失败或规则不一致自动出诊断文件
