## 测试流程摘要

### 首页（home.yaml）
1. wait-app-ready → Notes 首页
2. TC-001 无登录/无 Tab
3. UI STRICT（黄品牌、浅底、圆角卡片风格）

### 便签 CRUD（notes.yaml）
1. ensure-y22-clean-state → TC-003 空状态
2. + → New Note → TC-006 空 Save
3. 填 Y22Test Note A → Save → TC-005 置顶
4. 再增 Y22Test Note B → TC-002 B 在 A 上方
5. force-stop + relaunch → TC-013
6. 点 B → 详情 TC-008 → 返回
7. 删 B：确认框 TC-009 → Cancel TC-010 → Delete TC-011
8. 删 A → TC-012 空状态
9. Sheet 边界：TC-007 超 500 字（独立 phase）

### TC-015 卸载（破坏性）

```powershell
$env:Y22_APK_PATH = "F:\path\to\dailyscribble.apk"
$env:Y22_RUN_UNINSTALL = "1"
npm run test:aside:y22:uninstall
```
