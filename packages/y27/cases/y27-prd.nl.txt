## 测试流程摘要

1. **photos**：就绪 → My Photos / UI → seed → 取消上传 → 导入  
2. **viewer**：全屏 → Download → Delete（Cancel+Delete）→ 再导入  
3. **albums**：Albums → 空名 → Travel → Add Photos → Download All  
4. **lock**：Lock Album 1234 → 错密 → 对密 → 列表 🔒  
5. **persist**：force-stop → 图/相册仍在
