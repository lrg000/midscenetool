## 测试流程摘要

### 月历（home.yaml）
1. AC-001/TC-001 无登录、无 Tab
2. UI 首页 STRICT + AC-019
3. AC-002 今日蓝圈
4. **上一月 → 下一月**（AC-003/TC-002）
5. Today（AC-004/TC-003）
6. **点非今日日期 → 行程页 → 返回**（AC-006/TC-004）
7. 点今日 → 进入 day-schedule

### 行程 CRUD（day-schedule.yaml，三阶段防连锁失败）

**Phase 1 — 核心路径（先跑）**  
8. 清理残留 → AC-007 空状态  
9. 保存 Y20Test Schedule → AC-011  
10. 再增 Y20Test Schedule 2 → AC-008 升序  
11. force-stop ×2 → AC-016 持久化  

**Phase 2 — 删除 & 蓝点**  
12. AC-005/TC-010 蓝点 → Delete/Cancel/Delete → AC-015  

**Phase 3 — Sheet 边界（独立，失败不拖累上方）**  
13. AC-009 → AC-010 空 Save → AC-012 101 字（`ensure-new-schedule-sheet` 恢复弹层）

### AC-017 卸载清数据（破坏性专项）

```powershell
$env:Y20_APK_PATH = "F:\path\to\dailygrid.apk"
$env:Y20_RUN_UNINSTALL = "1"
npm run test:aside:y20:uninstall
```
