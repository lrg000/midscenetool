## 测试流程摘要

### Explore（explore.yaml）
1. wait-app-ready → Explore / Sticker Box
2. TC-001 无登录、底栏两 Tab
3. UI 彩色活泼风 STRICT
4. TC-002/003 分类可见并点 Cute
5. TC-004 3 列 Grid

### Detail（detail.yaml）
6. 点任一贴纸 → TC-005 详情
7. Download Sticker → TC-006 Sticker saved!
8. 再点 → TC-007 Downloaded
9. 返回 Explore

### My（my.yaml）
10. 底栏 My → My Stickers
11. Downloaded 含刚下贴纸 TC-015
12. force-stop + relaunch → TC-019
13. Uploaded Tab 可见（可不上传）

### TC-021 卸载（破坏性）

```powershell
$env:Y25_APK_PATH = "F:\path\to\app.apk"
$env:Y25_RUN_UNINSTALL = "1"
npm run test:aside:y25:uninstall
```
