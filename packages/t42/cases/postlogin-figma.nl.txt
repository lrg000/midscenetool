## TC-06 Verification Completed（认证结果 — 必须校验得分）

**Figma**：结果 `1:525`（见设计稿：绿色勾 + PROFILE SCORE **87/100** + Excellent Eligibility）

### 页面文案（verify — 必现）

| 元素 | Figma 精确文案 |
|------|----------------|
| 主标题 | Verification Completed |
| 副文案 | Your profile has been successfully assessed. |
| 分数卡标题 | Profile Score / PROFILE SCORE（实机多为全大写） |
| **得分（必校验）** | **XX/100**（Figma 示例 **87/100**；必须为 1–100 的整数，不可为空） |
|  eligibility | Excellent Eligibility |
| 推荐区标题 | Recommended Loan Types |
| 推荐磁贴 | Personal Loan / Home Loan / Vehicle Loan |
| 底部按钮 | Back to Home |

### 步骤

| # | 操作 | 期望 |
|---|------|------|
| 1 | 等待 Verify Face 完成 | 进入 **Verification Completed** 结果页（不可跳过） |
| 2 | **校验已获取 PROFILE SCORE 数值** | 可见 **XX/100** 格式得分（如 87/100），非空、非占位 |
| 3 | 校验结果页完整文案 | 见上表：标题、副文案、eligibility、Recommended Loan Types、Back to Home |
| 4 | 点击 **Back to Home** | 回到 Home，Home Tab 选中 |
| 5 | 校验已回 Home | AVAILABLE CREDIT LIMIT + Get Cash Now 可见 |

### 通过标准

- **必须**在结果页看到数值得分；未展示得分或仅回 Home 而无得分校验 → **失败**
- 得分分子为 1–100 整数；0/100 或空白视为未获取有效得分 → **失败**

### 自动化映射

- kyc-manual-until → 等待 "Verification Completed" + XX/100
- verify ×2 → 完整文案 + 得分非空专项断言
- tap-text → Back to Home（非 optional）
- verify → 已回 Home

## 五、生成自动化时的要求（研发）

1. **只改** `packages/t42/` 与 `tests/aside/t42*.test.ts`，**禁止**改 B 面 `data/business-*`
2. 每个可点步骤写 `locatePrompt` + **Do NOT tap …**
3. 输入类：`skipEmptyBlurTest: true` + `skipInvalidBlurTest: true`（A 面失焦常不校验）
4. 底部主按钮：`scrollBeforeTap: true` 或写入 `page.bottomFields`
5. 居中弹窗/协议：**不要** scrollBeforeTap
6. Delete：**只 Cancel**；Logout：**不执行**
7. 人工步骤：`kyc-manual-until` + `handle-permissions`
8. 注册 `config/packages.yaml` 的 `t42-postlogin.pages[]` 顺序与本文件 TC 顺序一致

### 建议 page 顺序（packages.yaml）

```
home → personal-information → document-upload → face-verification →
verification-result → personal-loan → business-loan → profile →
help-support → account-details
```
