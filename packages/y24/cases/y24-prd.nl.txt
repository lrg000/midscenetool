## 测试流程摘要

1. **photos**：就绪 → TC-001/UI → Grid/空态 → seed → TC-006 取消 → TC-004/005 导入  
2. **viewer**：全屏 → Download → Delete（Cancel+Delete）  
3. **albums**：校验空名/超长 → 建 Holiday → 空态 → Add Photos → Download All →（稍后删）  
4. **lock**：加密相册 + 错密/对密 + 删加密相册  
5. **persist**：force-stop 后数据仍在；再 Delete Album（TC-013/025）  
6. **uninstall**：`Y24_APK_PATH` + `Y24_RUN_UNINSTALL=1`

## PRD 明确不支持（不测）

登录 / 云同步 / 图片编辑 / AI / 搜索 / 标签 / 分类 / 社交 / 备份 / 视频 / 多账号 / 改密 / 批量删相册
