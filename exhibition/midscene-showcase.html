midscenetool / project showcase

用 AI 视觉 + YAML 配置，驱动 Android 借贷 App 自动化测试。

页面配置驱动 · AI Agent 执行 · 状态机编排。无需维护 XPath / UiAutomator，用自然语言描述 UI，由 Midscene 完成点击、输入与断言。

01 / Problem

移动端 H5 + 原生壳混合，传统定位器维护成本过高。

定位器脆弱

UI 微调即导致 XPath / resource-id 失效，回归成本高。

混合栈复杂

冷启动、权限、原生登录、WebView H5、KYC 原生页交替出现。

业务流多变

首页分流 Next / Apply / Repay，账号与包配置影响路径。

框架选择用自然语言 + 视觉理解描述元素，把「怎么点」交给 AI，把「测什么」留在 YAML。

02 / Mechanism

YAML 配置进入状态机，AI Agent 在设备上执行并回写报告。

data/*.yaml
flows.yaml state-machine
page-executor Midscene
AI Agent 断言 + HTML
JSON 报告
  • config/pages.yaml — 页面注册与 data 文件映射
  • core/state-machine.ts — 单页入口 runPageTest
  • core/business-runner.ts — 多页业务流 runBusinessFlow
  • core/aside-runner.ts — A 面按包 runAsidePackage

03 / Modes

按稳定性选择运行模式 — 日常推荐单页。

single-page ★★★

设备已在目标页，skipNavigation=true。例：npm run test:basic-info

segment ★★

分段串联，如 bootstrap + 登录，或 KYC 五步 kyc-full。

full-flow ★

bootstrap → 登录 → 分流 → 多页；依赖账号、环境与人工步骤。

环境变量：ACCOUNT_PROFILE · SKIP_BOOTSTRAP=1 · SKIP_LOGIN=1

05 / Evidence

每次运行产出可核对、可分享的报告与产物。

汇总用例结果，生成 HTML 可视化报告（通过率、分组、AI Token 等）。

midscene_run/

报告、截图、日志、缓存、Midscene 步骤报告统一落盘。

midscene_run/
├── report/          # HTML 步骤报告
├── output/          # 汇总报告
├── screenshots/     # 失败/关键步骤截图
├── log/             # 运行日志
└── cache/           # AI 缓存

可与数据库 MCP 联用：跑完用例后核对业务表落库（customer、borrow_apply 等）。

06 / Quick Start

从单页字段测试开始 — 最稳定的路径。

  1. cd F:\tools\midscenetool && npm install
  2. 配置 .env（Midscene 模型 API + 可选测试账号）
  3. USB 连接 Android 设备，adb devices 确认在线
  4. 手动导航 App 到 Basic info 页
  5. npm run test:basic-info
# 其他常用入口
npm run test:kyc-full
npm run test:business-auto
npm run test:business-apply
npm run test:aside:t42
npm run test:aside:y20

核心结论：YAML 描述测什么，AI 负责怎么点，报告证明测过了。
